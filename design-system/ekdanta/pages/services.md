# Page Override: Services (mobile)

> Overrides `design-system/ekdanta/MASTER.md` for the **mobile** composition (≤ 767 px, and 768–991 px scaled). Desktop follows MASTER. Exact per-section numbers (positions, distances, ranges) are transcribed from `docs/ekdanta-design/pages/mobile/M-Services.dc.html` into each section's motion defaults JSON; this file records the rules that differ.

**Artboard:** 390 × 844. **Gutter:** 24 px. **Header:** mobile pill (MASTER → Header) with the green WhatsApp button and the menu button; the full-screen menu is the `mm-panel` overlay. **Heading reveal:** rises 30 px, not 40. **Type:** the mobile column of the MASTER type scale.
